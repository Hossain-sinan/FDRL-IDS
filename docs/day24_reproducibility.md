# Day 24 — XGBoost Reproducibility Test

## 1. Objective

The main objective of Day 24 was to check whether the improved XGBoost experiment from Day 23 can be reproduced consistently.

For this test, I trained the XGBoost Config B model again from scratch using the same:

* CICIDS2017 dataset
* Data cleaning process
* Label processing
* 20 selected features
* Train/validation/test split
* Random seed
* XGBoost parameters
* Software environment

The purpose was not to improve the model again, but to verify that the Day 23 result was reproducible.

---

## 2. Reproducibility Conditions

The following conditions were kept exactly the same as Day 23:

| Condition             | Day 24     |
| --------------------- | ---------- |
| Dataset               | CICIDS2017 |
| Selected features     | 20         |
| Random state          | 42         |
| Validation size       | 10%        |
| Test size             | 10%        |
| XGBoost configuration | Config B   |
| SMOTE                 | Not used   |
| Class weighting       | Not used   |
| Tree method           | Hist       |
| Number of classes     | 8          |

The same preprocessing and feature selection pipeline were also used.

---

## 6. Prediction-Level Reproducibility

Metric comparison alone is not enough for a strong reproducibility test.

Therefore, the Day 24 predictions were also compared directly with the predictions generated by the saved Day 23 Config B model on the same test set.

Result:

```text
Prediction reproducibility: True
Different predictions: 0
```

This means every test sample received the same predicted class in both runs.

Therefore:

**Day 23 predictions = Day 24 predictions**

for all **252,079 test samples**.

---

## 7. Reproducibility Result

The experiment produced:

```text
Metric reproducibility: True
Prediction reproducibility: True

RESULT: REPRODUCIBLE
```

This is a strong result because the model was retrained from scratch rather than simply loading the previous model.

---

## 8. What This Result Means

The Day 24 experiment confirms that the Day 23 Config B result is not dependent on accidentally saving or reusing the previous model.

Under the same experimental conditions, the complete process produced exactly the same:

* dataset split
* evaluation data
* evaluation metrics
* predictions

This gives stronger confidence in the reliability of the XGBoost baseline.

It is especially useful for the later FDRL-IDS experiments because the centralized supervised model will be used as a baseline for comparison with the future DRL and Federated DRL approaches.

---

## 9. Scope and Limitation

The reproducibility result should not be interpreted as meaning that the experiment will always produce exactly the same result on every computer or software environment.

The exact reproduction was verified under the same:

* dataset
* preprocessing pipeline
* feature set
* train/validation/test split
* random seed
* XGBoost configuration
* software environment

Therefore, the scientifically correct conclusion is:

> Under the same dataset, preprocessing pipeline, feature set, train/validation/test split, random seed, XGBoost configuration, and software environment, the Day 23 Config B experiment was reproduced exactly in Day 24.
